Maintained by **Darshan Thorat**, this repository is meant to be a launchpad for anyone wanting to build practical software testing experience. It blends manual QA exercises with automation frameworks so learners can build a well-rounded skill set across the testing lifecycle.

## Manual QA Projects

### 🛒 E-commerce Platform QA
- **Goal:** Validate the functional, usability, and security aspects of an online shopping site.
- **Coverage:** Product search flows, account registration, cart operations, and checkout/payment handling.
- **You'll produce:** A test plan, detailed test cases, and bug reports.

### 🏦 Banking App QA
- **Goal:** Confirm the security and dependability of a banking application.
- **Coverage:** Login flows, money transfers, statement generation, and transaction-level security checks.
- **You'll produce:** A test plan, detailed test cases, and bug reports.

## Automation QA Projects

### ⚙️ Project A — Selenium WebDriver
- **Goal:** Build automated scripts for core web app functionality.
- **Coverage:** Login automation, form submission checks, data validation scripts.
- **Stack:** Selenium WebDriver + TestNG + Maven.
- **You'll produce:** Working automation scripts, execution results, and a framework design doc.

### ⚙️ Project B — API Testing via Postman
- **Goal:** Validate RESTful API behavior.
- **Coverage:** GET / POST / PUT / DELETE test scenarios.
- **Stack:** Postman + Newman.
- **You'll produce:** A full API test collection and accompanying test reports.

### ⚙️ Project C — Load Testing with JMeter
- **Goal:** Measure how a web app performs under load.
- **Coverage:** Performance test plans targeting critical app functions.
- **Stack:** Apache JMeter.
- **You'll produce:** JMeter test plans, performance metrics, and an analysis writeup.

## Getting Started

**1. Clone this repo:**
```sh
git clone https://github.com/darshanthorat/software-testing-projects.git
cd software-testing-projects
```

**2. Set up the tools you need:**
| Project Type | Requirements |
|---|---|
| Selenium | Java, Maven, Selenium WebDriver |
| Postman | Postman desktop/CLI app |
| JMeter | Apache JMeter installed locally |
